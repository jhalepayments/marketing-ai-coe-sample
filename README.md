# Jhale Payments: AI center of excellence for marketing

This is a small working example of how a marketing team could set up an AI center of excellence: shared skills that coach people through real work, a log of where those skills get stuck, and an inventory so teams reuse what exists instead of rebuilding it. It is set at Jhale Payments, a made-up payments company. Everything here is generalized and fictional, built on my own time and my own computer, and contains no material from any employer.

## Try it in 3 steps

1. Open this folder in Claude Code.
2. Type `/campaign-launch-coach`.
3. Answer the questions. Try giving a vague answer, like "send it next week-ish," and watch it stop, tell you who to ask, and log the gap in `gaps/gap-log.md`.

## What's in the folder

```
.claude/skills/
  campaign-launch-coach/   Coaches an outside contractor through an email launch, step by step
  brief-qa/                Checks a campaign brief for gaps before work starts
gaps/
  gap-log.md               Every time a skill stops and asks a human
  monthly-gap-review.md    How open gaps become skill updates each month
inventory/
  INVENTORY.md             Every skill, built or proposed, with owner and status
  intake-template.md       How anyone proposes a new skill
  scoring.md               How ideas are ranked, and built in-house or by an agency
  how-to-adapt.md          How to copy a skill and make it your team's own
examples/
  sample-session.md        A contractor using the coach, including one stop
```

## Why this exists

When many teams build similar things on their own, it costs money and repeats work. Two teams pay for two versions of the same checklist tool, and neither knows the other exists. The inventory makes what exists visible, so teams can reuse and adapt it, and the gap log makes sure every skill keeps getting better instead of quietly going stale.
